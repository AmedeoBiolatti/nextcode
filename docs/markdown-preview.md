# Markdown preview

Markdown files open with **Source**, **Preview**, and **Split** buttons above
the document. Source shows the normal text editor, Preview shows only the
rendered document, and Split shows both side by side with a draggable divider.
Split is the default; the selected mode is restored per tab with the session.
The same buffer owns edits, undo and saving in every mode. Preview updates as
you type, including unsaved changes, with parsing performed in the background.

The native preview supports headings, emphasis, lists, task lists, tables,
quotes, highlighted code fences and local images relative to the file's folder.
Rendered text can be selected and copied; links use the existing browser/system
handlers. Source and preview scroll independently.

Use **View > Markdown** or the command palette for the same three modes.
Shortcuts while a Markdown document has focus: **Ctrl+Shift+V** for Preview,
**Ctrl+K, V** for Split and **Ctrl+K, E** for Source (Cmd instead of Ctrl on
macOS). **Ctrl+S** also saves from Preview mode.
